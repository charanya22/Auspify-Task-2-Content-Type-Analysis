# Task 2: Content Type Analysis Dashboard

**Internship:** Auspify Technologies  
**Domain:** Data Analysis Using Python

## Objective
Analyze the distribution of Movies and TV Shows in the Netflix dataset.

## Technologies Used
- Python
- Pandas
- Plotly
- Streamlit

## Project Workflow
1. Load the Netflix dataset.
2. Calculate the total number of Movies and TV Shows.
3. Visualize content distribution using bar and pie charts.
4. Compare the proportions of each content type.
5. Summarize key findings.

## Dashboard Features
- Total content statistics
- Movie and TV Show comparison
- Interactive visualizations
- Content-type filtering
- Data preview and CSV download

## How to Run
Install the dependencies:

```bash
pip install pandas streamlit plotly
```

Run the dashboard:

```bash
python -m streamlit run app.py
```

## Outcome
An interactive dashboard for exploring Netflix content distribution.
